# Portfolio v2: how to push it

This bundle mirrors the repo layout (index.html, CSS/, JS/, Public/, Assets/).

1. Copy everything over the repo root, replacing files.
   Assets/ in this bundle holds the new Verdentra images (verdentra-*.jpg) only.
   Your existing Assets are untouched.
2. Delete old files nothing uses any more:
   CSS/igvirnm.css, CSS/nlds.css
   JS/aboutme.js, JS/blogs.js, JS/contactme.js, JS/igvirnm.js, JS/nlds.js
3. Commit and push (Netlify rebuilds).
